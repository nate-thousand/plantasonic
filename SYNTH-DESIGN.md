# Synth Design

> An AI Native Design Framework for Interactive Audiovisual Experiences

**Version:** 0.1  
**Status:** Living Document  
**Primary Project:** Plantasia (shipped) · **Active fork:** Juno Flowers (local)

---

# Overview

Synth Design is a design methodology for creating interactive experiences where **sound, visuals, motion, light, physical interaction, and computation** are treated as one integrated system.

Rather than separating product design, sound design, motion design, visual design, installation art, and software engineering, Synth Design combines them into a unified creative process.

Plantasia is the first application built using this methodology. [Juno Flowers](juno-flowers/) is an active local fork focused on Juno Flow mode and the ASCII flower garden experience.

---

# Mission

Design experiences that blur the boundaries between software, instruments, environments, and art.

Every interaction should feel expressive.

Every system should respond.

Every experience should invite exploration.

---

# Vision

Create a universal design language for interactive audiovisual experiences.

Just as Material Design established a common language for digital interfaces, Synth Design aims to establish a common language for designing systems that combine:

- Sound
- Motion
- Light
- Visual Design
- Space
- Interaction
- Computation
- Artificial Intelligence
- Physical Objects
- Installation Art
- Human Performance

---

# Core Philosophy

Software should feel like an instrument.

Objects should feel alive.

Rooms can become instruments.

Light can become an interface.

Plants can become controllers.

Architecture can become responsive.

The user is not operating software.

The user is performing.
