## Summary

The Plantasonic Design System is the visual operating system for the Plantasonic ecosystem — not another UI kit. Every application inherits its identity from this system.

Before creating, modifying, or implementing any UI:

1. Read the full [Vision and Scope](https://github.com/nate-thousand/plantasonic-design-system/blob/main/docs/VISION_AND_SCOPE.md) document
2. Apply the [decision filter](https://github.com/nate-thousand/plantasonic-design-system/blob/main/docs/VISION_AND_SCOPE.md#decision-filter) before adding tokens, components, or patterns
3. Edit tokens only in `plantasonic-design-system/tokens/` — never in this app

---

## Decision filter (quick reference)

1. Does this improve clarity?
2. Does this strengthen consistency?
3. Does this reduce duplication?
4. Does this support accessibility?
5. Does this make future Plantasonic applications easier to build?
6. Does this feel unmistakably Plantasonic?
7. Can this be reused across multiple applications?
8. Does it simplify rather than complicate the system?

If the answer to any is "no," reconsider the addition.
